# Instrucciones para añadir screenshots a F-Droid

## 📸 Pasos para capturar screenshots:

### 1. Captura estas pantallas importantes:
- [ ] **Pantalla principal** - Lista de plantas
- [ ] **Detalle de planta** - Vista completa con información
- [ ] **Agregar planta** - Formulario de nueva planta  
- [ ] **Galería de fotos** - Vista de fotos de una planta
- [ ] **Configuración** - Pantalla de preferencias
- [ ] **Widget** - Widget en home screen (opcional)

### 2. Formatos requeridos:
- **Formato**: PNG o JPG
- **Nombre**: Screenshot_01.png, Screenshot_02.png, etc.
- **Tamaño**: Mínimo 1080x1920 (recomendado 1440x2560)
- **Sin bordes** del dispositivo

### 3. Copia las screenshots aquí:
```
C:\Users\javis\AndroidStudioProjects\PruebaAndroid\fastlane\metadata\en-US\phoneScreenshots\
```

### 4. Comandos para copiar (ejemplo):
```bash
# Si capturaste en Pictures/Screenshots
cp "C:\Users\javis\Pictures\Screenshots\Screenshot_01.png" "C:\Users\javis\AndroidStudioProjects\PruebaAndroid\fastlane\metadata\en-US\phoneScreenshots\"
cp "C:\Users\javis\Pictures\Screenshots\Screenshot_02.png" "C:\Users\javis\AndroidStudioProjects\PruebaAndroid\fastlane\metadata\en-US\phoneScreenshots\"
```

### 5. Requisitos de F-Droid:
- ✅ Máximo 8 screenshots
- ✅ Sin texto superpuesto (excepto UI de la app)
- ✅ Sin marcos de dispositivos
- ✅ Contenido real de la app, no mockups

## 🚀 Una vez añadidas las screenshots:
Tu aplicación estará 100% lista para F-Droid submission.
